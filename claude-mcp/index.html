claude-mcp

A personal connector between Claude Code and my own Google accounts.

claude-mcp is the Google OAuth client used by a locally running Google Workspace MCP server. It lets Claude Code, an AI coding assistant running on my computer, read and manage the Google Calendar, Google Drive and Gmail data of the Google accounts I own, when I ask it to.

This is a personal tool. It is not offered to the public, it has no sign-up, and it is used only by Gabriele Consiglio with his own Google accounts.

What it does

  • Calendar: list calendars and events, check availability, create and update events.
  • Drive: search, read and create files.
  • Gmail: search and read messages, draft and send email, manage labels.

How it works

The MCP server runs on my own Mac. When I sign in, Google issues OAuth tokens that are stored only on that machine. The server calls Google APIs on my behalf and returns the results to Claude Code in the same session. There is no server, database or account operated by this app anywhere else.
